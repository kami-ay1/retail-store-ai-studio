# 项目验证记录

## 已完成

- Vue 3 与 Node.js 服务启动成功，页面和健康检查均返回 HTTP 200。
- TypeScript 与 Vue 类型检查通过。
- 十三项自动化测试通过：CSV 引号与中文字段解析、UTF-8 编码校验、必填数值校验、超过一千条商品的完整读取、整份文件校验后写入、商品版本冲突、真实 HTTP 注册与商品保存、同邮箱并发注册、Agent 工具权限、方案保存、真实 JPEG 图片解码与本地存储、参考图大小边界及生成图片域名限制。
- Qdrant 1.20.0 官方 Windows 服务已运行，使用本机中文 BGE 模型生成真实 512 维向量。十一组集成验收通过，覆盖自然语言搜索、中文单字符、商家隔离、库存与品类过滤、商品编辑、CSV 更新、商品版本校验、Agent 检索工具、真实 HTTP 接口、服务重启、新集合重新同步及连接失败。测试运行器与既有测试合计统计 25 项通过。
- 浏览器中创建独立的“语义检索验收工作室”，通过实际商品表单新增验收商品。输入“夏季办公室日常穿着，清爽不闷热”后，页面通过真实语义检索返回“云絮衬衣（验收商品）”；商品资料中没有该查询原句。页面提供语义选品入口、库存筛选和索引状态。
- 浏览器中通过真实注册表单创建本地验收账户，并进入工作台。
- Coze 工作空间中创建生图工作流，配置两个 Image 输入、prompt 输入、Seedream 5.0 Lite、竖版 3:4 及 image_url 输出，并连接三个节点。
- Coze 中创建“魔柚商品工具”端插件并发布 v0.0.1，包含 search_products、get_product 和 propose_outfit。
- Coze 中创建“魔柚搭配策划”Agent，保存提示词并绑定三个商品端插件工具。
- 生图工作流与搭配 Agent 按当前要求保留草稿；本地配置中关闭对应模型 API 调用。

## 尚未验证
